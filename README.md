# 文字化けメモ超 (Mojibake Memo)

**「保存するたびに、あなたの記憶が少しずつ失われる」**
史上最低のUXを提供する、絶対に実務で使ってはいけないメモ帳アプリです。

## 概要

このアプリは、入力されたテキストを保存する際、意図的に **UTF-8とShift_JISのエンコードのすれ違い** を発生させ、ガチの文字化け（例：`縺薙ｓ縺ｫ縺｡縺ｯ`）を引き起こします。

さらに恐ろしいことに、このアプリの「復元機能」は完璧ではありません。文字コード変換時の欠損を利用しているため、復元を試みても一部の文字が永久に失われ、虫食い状態の絶妙にイライラするテキストが生成されます。

## 特徴 (Features)

* **確実なデータ破壊:** 保存ボタンを押した瞬間、大切なメモが読解不能な文字列に変換されます。
* **不完全な復元:** 「復元を試みる」ボタンを押すと元の言語に戻りますが、一部の漢字や助詞がランダムに欠損します。
* **ローカル保存:** 破壊されたデータは、ご丁寧にあなたのブラウザ（LocalStorage）に永続化されます。

## 技術スタック (Tech Stack)

* HTML / CSS / Vanilla JavaScript
* [encoding-japanese](https://github.com/polygonplanet/encoding.js) (文字コードの強制変換・逆変換に使用)

## 遊び方 (Usage)

1. `index.html` をブラウザで開きます。
2. 絶対に忘れたくない大切な要件（例：「明日の15時に渋谷駅ハチ公前」など）を入力します。
3. **「メモを保存（破壊）する」** をクリックします。
4. 見事に文字化けしたログを眺めて絶望します。
5. **「復元を試みる」** をクリックし、ギリギリ読めそうで読めない欠損テキストを楽しみます。
